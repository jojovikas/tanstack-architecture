# React Query CRUD Playground

A React application demonstrating TanStack Query (React Query) fundamentals with a real REST API.

## Features

- Fetch Users (useQuery)
- Create User (useMutation)
- Update User (useMutation)
- Delete User (useMutation)
- Query Invalidation
- Server State Management
- Query Caching
- Loading & Error Handling
- Environment Variables
- Custom Hooks Architecture

## Tech Stack

- React
- Vite
- TanStack Query
- JavaScript
- Tailwind CSS
- REST API
